# Hardware evidence

Observed local test platform: Windows 11 x64, Intel Core i9-11900F, approximately 32 GiB RAM, multiple fixed and removable volumes. Detailed local scan output is intentionally not embedded in public documentation.

This is one platform, not a validated hardware matrix. AMD GPU, Intel GPU, laptop battery, SATA/HDD/NVMe behavior across devices, microphone capture, webcam control, audio interfaces, mixed-DPI monitors and long-running vendor workloads remain untested. Unsupported telemetry is explicitly unavailable.

Do not upgrade any hardware-dependent feature to production readiness on the basis of the current snapshot scan alone.
