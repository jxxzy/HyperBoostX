# Commercial Roadmap

HyperBoostX v2.0.0 does not enforce paid licensing and does not require online accounts for core safe features.

## Principles

- Safety Guard, restore visibility, and privacy controls must never be locked behind a paywall.
- Core scan/report/restore flows should remain usable offline.
- No hardcoded secrets.
- No telemetry without opt-in.
- License checks must fail gracefully.

## Possible Future Tiers

- Free stable version with local optimizer, Safety Guard, reports, and restore.
- Optional Pro/Lifetime features such as advanced report templates, extended benchmark analysis, or professional support.
- Optional license server with offline grace period.

## Current Status

Roadmap only. No v2.0.0 feature is license-locked.
